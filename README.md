# TechToJob — Torneo #2

Landing inicial en React + Next.js + TypeScript + Tailwind.

## Ejecutar

```bash
npm install
npm run dev
```

Abre http://localhost:3000

La propuesta toma como base la referencia adjunta, pero mejora la jerarquía: hero claro, núcleo de marca, cuatro conexiones, secciones para talento/empresas y CTA final. Los iconos son SVG vectoriales, no emojis.
